# Đặc trưng từng class và ascendancy

POE2 0.5 = 8 class chơi được, mỗi class gắn 1–2 attribute + vũ khí đặc trưng. Class quyết định vị trí start trên tree, vũ khí hợp, và ascendancy mở được.

## Ba attribute định hình class

- **Str** → armour + đòn vật lý nặng. **Dex** → evasion, tốc độ, tầm xa. **Int** → energy shield + spell.
- Class start gần vùng attribute nào thì node hợp cũng gần đó → class quyết hướng build tự nhiên (không khóa cứng).
- Marauder, Duelist, Shadow, Templar chưa mở — để dành 1.0.

## Ascendancy dễ cho người mới

- **Titan** (Warrior): armour + stun cao, tank dễ, đơn giản.
- **Infernalist** (Witch): dog companion + demon form, minion gánh — dễ nhất.
- **Stormweaver** (Sorceress): maintain shock → mọi đòn nguyên tố +20% damage.
- **Deadeye** (Ranger): projectile + tốc độ, clear pack nhanh.
- **Gemling Legionnaire** (Mercenary): linh hoạt attribute/gem.
- Mới 0.5: :wiki-link{url="https://www.poe2wiki.net/wiki/Spirit_Walker"} (Huntress — companion beast), :wiki-link{url="https://www.poe2wiki.net/wiki/Martial_Artist"} (Monk — illusory bell, rune khắc thân).

## Chọn class bắt đầu

- Người mới ưu tiên class dễ sống: Warrior tank; Sorceress/Mercenary tầm xa; Witch minion chịu trận → 3 hướng dễ xong campaign nhất.
- Monk/Huntress mạnh khi quen combo/timing nhưng sai nhịp dễ chết → để dành khi quen.
- Chọn class theo skill muốn chơi, không theo "class mạnh nhất". Mọi class dùng mọi gem nếu đủ attribute.
