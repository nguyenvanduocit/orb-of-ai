# Waystone và Atlas: bước vào endgame mapping

Xong campaign → endgame = chạy map qua **Waystone** (item bỏ vào Map Device mở cổng area endgame). Hiểu Waystone + Atlas tree = không bị "hết map".

## Waystone
- Item tiêu hao 1 lần: bỏ vào **Map Device** (bàn thờ vòng tròn phát sáng mỗi town Atlas) → activate → vào; Waystone hết = cổng đóng, chết không vào lại kịp → mất map
- **Tier 1–16**: tier cao → area level cao, quái mạnh, loot tốt. T1 = area level 65, mỗi tier +1 → **T16 = area level 80**
- T16 KHÔNG drop trực tiếp từ monster → ghép **3 T15 cùng rarity @ Reforging Bench** = T16 chắc chắn; Vaal Orb lên T15 cũng ra T16 nhưng random (tier ±1)
- Không mua vendor giá cố định → drop từ monster/boss/trade → sustain là kỹ năng (drop < dùng thì cạn kho)
- Phải **identify bằng Orb of Identification** trước, chưa identify không activate được

## Mod trên Waystone
- Sau identify: magic (2 mod) / rare (4 mod). 2 loại tác dụng: **buff loot** (increased item rarity, pack size, waystone drop chance) + **khó chơi** (monster extra damage, reduced player max resistance, increased monster life)
- Nhiều mod → lãi hơn nhưng khó hơn: đầu endgame transmute+augment lên 2 mod đủ; red tier (T11+) → :wiki-link{url="https://www.poe2wiki.net/wiki/Orb_of_Alchemy"} lên rare 4 mod
- ⚠ Mod nguy hiểm ("-% maximum resistance") đọc kỹ trước activate — kill build chưa cap resist
- **Waystone drop chance tăng theo số mod**: map 6 mod gần như chắc nhả thêm Waystone (đặc biệt từ boss)

## Atlas + Atlas passive tree
- **Atlas** = lưới map endgame kết nối, mỗi ô 1 địa hình → chọn ô + dùng Waystone tương ứng
- **Atlas passive tree** = cây riêng, tách tree nhân vật (không dùng điểm char, không ảnh hưởng combat) → chỉ buff map: thêm rare monster, tăng drop, bật content (Breach/Ritual/Delirium...), tăng Waystone drop
- Điểm Atlas tree (0.5) chỉ từ **1 nguồn: chạy map trong Fortress** (mỗi map rớt ≥1 point); đủ point → allocate cả cây **300+ node**; KHÔNG respec, nhưng multi-choice node đổi tự do

## ✗ Vì sao người mới hết map
- Vòng chưa tự nuôi: chưa Atlas point → tree trống → Waystone drop ít → ít map → point chậm. Phá vòng cần 2 thứ:
- **Số mod Waystone**: Waystone trơn (0 mod) drop rate rất thấp → đẩy magic→rare để Waystone rớt đủ nuôi vòng (thà chạy map dễ với Waystone nhiều mod hơn map khó với Waystone trơn)
- **Precursor Tablet**: gắn vào tháp Atlas trước khi chạy → buff mọi map trong bán kính; mod "increased quantity of Waystones" = nguồn sustain mạnh nhất đầu game; 2 tablet quantity cùng khu = bước nhảy lớn

## Bước đầu vào endgame
- Map đầu → **Precursor Tower** hiện ngay → clear → **Fortress** mọc lên = khu chạy lấy Atlas point
- Chạy map trong Fortress nhặt point theo đường (đừng cày sạch, đi theo mũi tên tới boss khu vực); luôn dùng Waystone nhiều mod nhất + gắn tablet trước activate
